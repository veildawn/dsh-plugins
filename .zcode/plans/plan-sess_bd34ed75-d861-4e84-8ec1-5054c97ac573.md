## 目标

移动端文件查看悬浮按钮:换成宿主设计系统的配色,并支持手指拖动改位置、松手吸附到最近一侧边缘、位置记住。

只改 `plugins/dsh-file-viewer/lib/client.js` 和它的测试。

## 现状问题

按钮现在是**完全硬编码**的深色圆钮:

```css
.fv-float-entry{...background:var(--dsw-alias-bg-inverse,#1f1f1f);
  color:var(--dsw-alias-label-inverse,#fff);
  box-shadow:0 4px 14px rgba(0,0,0,.28);...}
```

`--dsw-alias-bg-inverse` 和 `--dsw-alias-label-inverse` **在宿主主题里并不存在**(我在 `dsh-client-ui-theme/lib/styles/design-platform.css` 里逐个核对了 162 个 token 定义),所以实际渲染永远是那两个字面量回退值。后果是它不跟随浅色/深色主题,阴影也比宿主任何一级都重(宿主最重的 `--dsw-shadow-lv3` 也只有 `rgba(0,0,0,.08)`)。

宿主自己有一个圆形悬浮按钮(会话里的"回到底部"),配方是:`--dsw-alias-button-floating-fill` + `1px solid --dsw-alias-border-l2` + `--dsw-shadow-lv2` + `--dsw-alias-label-primary` 图标。我按这个来。

## 一、外观

`.fv-float-entry` 改为:

```
background      var(--dsw-alias-button-floating-fill)
border          1px solid var(--dsw-alias-border-l2)
box-shadow      var(--dsw-shadow-lv2)
color           var(--dsw-alias-label-primary)
width/height    48px（从 46 提到 48，圆整且高于 44 的触控下限）
transition      transform var(--ds-transition-duration-fast,.1s) var(--ds-ease-in-out)
```

副作用要先说清楚:**浅色模式下按钮会从深色变成近白色带描边**,深色模式下自动转深。这是宿主 token 的极性,和你截图里现在的深色圆钮不同。如果你更想保留深色高对比,我改用 `--dsw-alias-toast-bg` + `--dsw-alias-label-primary-inverted`(这两个是真实存在的 token),一行的事。

另外补一条 `prefers-reduced-motion` — 现有那条 `@media(prefers-reduced-motion:reduce)` 只关掉了 `animation`,没管 `transition`,按 mobile-adapter 的写法把 `transition` 也一起中和。

## 二、拖动

行为:手指按住可拖,按钮实时跟手;松手后水平方向吸到最近的左边或右边,垂直保留在松手高度;位置写进 `localStorage`,下次进来还在原处。

### 落位计算做成纯函数

`client.js` 不能 import `core.js`(浏览器 bundle 自带副本,这是文件里已有的约定),所以纯函数放在 `client.js` 内部并挂到 `internals` 上,由 `package.test.mjs` 通过现有的 `definition.factory(...)` 取出来测 —— 这是文件里第 142-146 行已经在用的模式。

```js
function settleEntry({ x, y, size, viewport, safe, margin })
// → { side: "left" | "right", bottom: <px> }
```

职责:判断 x 落在哪半边决定 `side`;把 y 夹在合法区间内,上不钻进移动端顶栏(`52px + --dsh-sat`),下不掉出安全区。夹取是必须的 —— 否则转屏或键盘弹出后按钮可能停在屏幕外再也点不到。

### 手势

在按钮上挂 `pointerdown` / `pointermove` / `pointerup` / `pointercancel`,用 `setPointerCapture` 保证手指移出按钮后仍能收到事件。

区分点按和拖动用位移阈值(约 8px):没超过就是点按,照常开抽屉;超过了就是拖动,并在随后的 `click` 上拦一次,避免松手瞬间误开抽屉。

`pointercancel` 会处理 —— mobile-adapter 的 swipe 漏了这个,手势被系统打断时状态残留,我不重复那个问题。

按钮加 `touch-action:none`,否则拖动会被浏览器当成页面滚动。

### 持久化

沿用 `dsh-remote-control` 的约定(`lib/client.js:61-75`):键名 `dsh-file-viewer.entry-position`,读写都是 `globalThis.localStorage?.` 可选链再套 `try/catch`(Safari 隐私模式下访问 localStorage 本身就会抛),读失败回退到默认右下角。读的时候校验一遍再用,存量坏数据不至于让按钮消失。
